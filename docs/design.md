# Campus Spaces design specification

Reference: `design-concept.png` (1505 × 1045). Generated for this project before implementation.

## System

- White sidebar and panels; cool near-white page background; forest green primary actions and selected states.
- Sans-serif typography, strong dark headings, muted slate secondary text, fine neutral borders, restrained 8–12px radii.
- Desktop: persistent left navigation, main heading, three summary cards, date/time controls, category tabs, floor-plan panel with adjacent booking details.
- Floor plan: neutral architectural lines, outlined available desks, muted occupied desks, solid green selection. Interactive controls stay native to the application.
- Mobile: navigation condenses; filters wrap; booking details stack below the floor plan; all controls remain accessible.

Choose a date and interval, filter spaces, choose a desk or room, review the reservation, and confirm. My bookings lists persisted reservations and supports cancellation. Favorites stores device-local selections.

## Intentional functional extensions

Live counts and dates replace static reference values. Building and floor controls expose seeded campus spaces. Booking confirmation, cancellation, help, favorites, loading, and error states extend the same design system. A demo identity label states the authentication limitation. No decorative image assets are required by this app surface.
